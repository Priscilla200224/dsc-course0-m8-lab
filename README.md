# Aviation Accident Analysis

## Project Overview

This project analyzes aviation accident data to explore patterns in aircraft accidents, injuries, and aircraft damage. The goal is to use data cleaning and exploratory data analysis (EDA) to identify useful insights and make recommendations concerning small and large airplanes.

## Project Objectives

- Clean and prepare the aviation accident dataset for analysis.
- Explore accident patterns by aircraft make and model.
- Analyze injury outcomes and aircraft damage.
- Investigate how factors such as weather conditions and phase of flight relate to accident outcomes.
- Provide data-driven recommendations for small and large airplanes.

## Project Notebooks

1. **Aviation Accidents Cleaning:** Cleans and prepares the dataset, handles missing and inconsistent values, and creates variables for further analysis.
2. **Aviation Accidents Data Analysis:** Performs exploratory data analysis, summarizes accident outcomes, and presents visualizations and recommendations.

## Key Areas of Analysis

- Injury outcomes by aircraft make and model.
- Aircraft destruction rates.
- Accident patterns across weather conditions.
- Accident outcomes by phase of flight.
- Comparisons between small and large airplanes.

## Recommendations

Aircraft selection should consider injury outcomes, aircraft damage patterns, and the intended operating conditions. The analysis can help identify aircraft models worth further investigation.

The findings should be interpreted cautiously because the dataset contains accident records rather than all flights. Therefore, the results alone cannot establish the probability of an accident for a particular aircraft or prove that a specific factor causes an accident.
